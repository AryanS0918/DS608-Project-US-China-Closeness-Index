# Processed data
Derived country-year and country-anchor-year tables produced by the scripts in src/data/. These files are committed so the final index can be rebuilt without access to the raw source files. Rebuild order: build_sipri_arms_transfers, then build_security_subindex, build_diplomatic_subindex, build_economic_subindex, build_closeness_index, build_orientation_classification (run each as python -m src.data.<name> from the repository root). Upstream stages that read raw or source files (GSDB sanctions, Diplometrics, IMF DIP, treaty and FDI workbooks, UN Comtrade) need those files locally; see docs/data_acquisition/ and docs/source_register.md.
